# Frontier Command — Roadmap

This is the prioritized roadmap. Keep it short enough to guide the next work session. Detailed progression sequencing remains in `PROGRESSION_ROADMAP.md`.

## NOW

- Ship and verify `FC-002`: Worker idle/walk/mining headings, especially southeast and southwest.
- Ship and verify `FC-003`: direct non-stacking Satellite Uplink intel for player and AI without Relay ownership.
- Confirm the construction tray no longer clips or stacks words vertically on iPad and iPhone portrait widths.
- Keep Sites/GitHub synchronization and the verified release tag as permanent release gates.

## NEXT

- Continue the 2.5D art pass after the Tank. Prioritize the most visually inconsistent battlefield unit, then update one unit at a time with eight readable directions.
- Add deterministic simulation tests for mining/drop-off, construction queues/refunds, worker retreat/resume, fog-limited AI relay targeting, production sources, and save hydration.
- Expand persistent Command progression one isolated path at a time: Reinforced Frames, then Tactical Intelligence behaviors.
- Run and document a two-device private multiplayer pass, especially Tactical Fog perspective, room failure/retry, pause/menu behavior, and host/guest state swapping.
- Break the monolithic match implementation into data/rules, simulation, rendering, input, AI, and UI modules without changing gameplay behavior.

## LATER

- Blueprint currency and limited pre-match loadouts: artillery crawler, shield unit, scout, then combat engineer.
- One complete story mission with externalized objectives, dialogue, rewards, and unlocks before building a larger campaign.
- Additional ground and air production options after the current counters and economy are stable.
- Stronger account-backed persistence only if local saves become inadequate.
- Unity renderer/input migration while reusing data-driven balance, progression, and mission definitions.

## Explicitly not on the active roadmap

- Restoring web elevation/cliff gameplay.
- Restoring a mixed-army damage bonus.
- Moving Tanks or Drones back into Barracks production.
- Reintroducing separate local commander save slots.
